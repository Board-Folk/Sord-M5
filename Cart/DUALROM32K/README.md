# DUALROM32K v2

![Image of DUALROM32K version 2 cartridge board in white with FALC labelled EPROMs](https://github.com/Board-Folk/Sord-M5/blob/main/images/DUALROM32Kv2_Small.png)

A modified version of the M5E-00 cartridge board with a 62256 32K RAM chip replacing the 6116 RAM on board. Suitable for ROM images requiring or capable of using 32K RAM.
